FAQ — quick answers

Is it for TV?
No — designed for phones. Android 8+ phones, including older devices. No TV support, focused on perfect phone experience.
Does it work offline?
Yes — works fully offline. Finds videos, saves posters/subtitles for offline viewing, plays without internet. Only uses internet to check updates when connected and to fetch movie info/subtitles — all saved for offline later.
How to update?
Install new APK over old — keeps data. Or inside app: Settings → Check for updates → Download & Install. Shows progress, uses FileProvider + REQUEST_INSTALL_PACKAGES permission for self-update (user-initiated, requires system installer confirmation).
REQUEST_INSTALL_PACKAGES — why?
For in-app self-updater. App checks GitHub releases, downloads APK to cache, triggers system installer. No silent install — user must grant "Install unknown apps" and confirm Install. Fallback opens GitHub releases page. Allowed as self-updating app per F-Droid/Izzy policy (like F-Droid client).
Dependency Info block warning?
Fixed in v2.6.120+. Added android.dependenciesInfo { includeInApk=false includeInBundle=false } to build.gradle.kts. Previous APKs contained Google dependency metadata block — now removed. Scan now passes.
Where are my videos?
OptiCast uses MediaStore to find videos in Movies, DCIM, Download. If missing: Settings → Excluded folders → remove exclusion, Library → pull to refresh. Files starting with dot or in Android/data are hidden by system.
