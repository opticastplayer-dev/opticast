Use your own signing key for modified builds. The official signing key is private and is not included. Build/install instructions explain how to install a separately signed development package alongside the official app.

mpv is the default for local videos, with one-time Media3 fallback. Media3 handles network sources. This native build is rebuilt from pinned sources, not the unaudited mpv-android Maven AAR. It uses OpenGL ES rather than Vulkan, with Lua disabled. Local-file playback is the supported integration scope; choose Media3 for network sources and EQ/boost.

Hardware decoding is requested first, but software fallback, supported formats, HDR output and performance depend on the file and device. No universal compatibility or startup-speed claim is made.
