# OptiCast — Best Local Video Player for Android

## 🎬 Beautiful, Fast, Offline-First, No Ads, Open Source

**OptiCast** is a beautiful, fast local video player for Android — inspired by Infuse. Your own movies and TV shows, organized beautifully, playing perfectly offline.

**No ads, no tracking, completely free, open source.**

### 🚀 Features

#### Library
- **Auto-scan:** Finds your videos automatically, smart organization
- **Beautiful grid:** Changeable layout (Compact / Comfortable), smooth scrolling, hide bottom bar on scroll
- **Smart discovery:** Continue Watching, Featured, Recently Added, Movies, TV Shows, Collections, Favorites, Stats
- **Easy filtering:** Sort by Recent/Title/Rating/Year, genre filter, search, multi-select share/delete

#### Movie & TV Info
- **Auto-identifies:** Recognizes movies and TV shows from filenames, fetches posters and info
- **Beautiful artwork:** Posters and backdrops cached for offline, never shows black background
- **What's New:** Shows what's really new in each update — clear, compact, dismissible

#### Subtitles — Always Saved Offline
- **Finds subtitles:** Searches multiple sources together
- **Works offline:** Downloads and saves subtitles during scan for offline viewing
- **Powerful:** Dual subtitles (two languages at once), sync adjustment, all formats (SRT, ASS, VTT)

#### Video Player — Plays Everything
- **Powerful engine:** Plays all video formats, smooth playback
- **Beautiful player:** Edge-to-edge design, easy controls, speed control, aspect ratio, subtitle/audio picker
- **Gestures:** Double-tap to seek, swipe for volume/brightness, pinch to zoom, hold for fast forward, scrub preview
- **Smart features:** Sleep timer, auto-play next episode, chapters, notification controls, Picture-in-Picture

#### Updates — Simple and Offline-Friendly
- **Smart checking:** Checks for updates only when internet is available, uses minimal data
- **Clean library:** No annoying "Up To Date" spam — only shows when real update is available
- **Easy install:** Download and install inside the app, shows progress, no browser needed, clearly shows what's new

#### Performance
- **Fast and smooth:** Optimized for quick startup and smooth scrolling
- **Lightweight:** Small download size, efficient, works great even on older phones
- **Reliable:** Thoroughly tested, stable, handles corrupted files gracefully

### 📦 Installation

#### GitHub Releases (Recommended) — Latest v2.6.90
1. Go to https://github.com/opticastplayer-dev/opticast/releases
2. Download `OptiCast-v2.6.92-optimized.apk` from latest release
3. Install APK (allow unknown sources)
4. Open → Grant video permission → Auto-scan → Enjoy!
5. Settings → Check for updates → Download & Install in-app

#### F-Droid
- **Available:** https://f-droid.org/packages/com.opticast.player
- Auto-updates from GitHub releases

### 🔨 Build

```bash
cd project && ./gradlew assembleRelease
```

Requires Android Studio Ladybug+ (Android 8+, JDK 17)
