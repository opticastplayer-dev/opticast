Own F-Droid Repository

Get OptiCast updates directly via F-Droid client, without waiting for official F-Droid review. This is useful after IzzyOnDroid AI policy rejection — similar to how other AI-assisted apps distribute.

Why own repository?

Official F-Droid inclusion (MR !50919) is under review. IzzyOnDroid #659 was closed due to AI assistance policy. An own repository lets you receive verified builds directly from the developer with the same signature, using the F-Droid client you already trust.

How to add

  1. Install F-Droid client from https://f-droid.org/
  2. Open F-Droid → Settings → Repositories → + (Add new repository)
  3. Enter URL: https://opticastplayer-dev.github.io/opticast/fdroid/repo
  4. Fingerprint will be shown after repository is published (will be added here)
  5. Enable repository → Search OptiCast → Install

Alternative: Use Obtainium — add GitHub Releases URL https://github.com/opticastplayer-dev/opticast/releases and get updates directly.
