How to add custom repository

  1. Install F-Droid client from https://f-droid.org/
  2. Open F-Droid → Settings → Repositories → Add new repository
  3. Enter URL: https://opticastplayer-dev.github.io/opticast/fdroid/repo
  4. Enable repository → Search OptiCast → Install

Alternative: Use Obtainium with GitHub Releases URL https://github.com/opticastplayer-dev/opticast/releases for direct updates.
